# قياس — قائمة اختبار قبول المستخدم (UAT) — العربية

راجع `docs/qiyas-test-data-guide.md` للاطلاع على حسابات الاختبار والسيناريوهات
المُهيّأة مسبقًا المشار إليها أدناه. يجب تعبئة حقول "النتيجة الفعلية" و"نجاح/فشل"
و"المختبِر" و"تاريخ الاختبار" أثناء جولة الاختبار — هذا المستند يُسلَّم وهذه
الحقول فارغة عن قصد.

صيغة معرّف حالة الاختبار: `UAT-<الدور>-<الرقم>` (نفس المعرّفات الإنجليزية
للمطابقة المرجعية بين النسختين).

## المدير العام (Super Admin)

### UAT-SA-01 — إدارة قوالب البريد الإلكتروني للبرنامج
- **المتطلبات المسبقة**: تسجيل الدخول بحساب `superadmin`.
- **الخطوات**: 1) الانتقال إلى الإدارة ← قوالب البريد. 2) فتح قالب
  `requirement_assigned`. 3) تعديل نص المحتوى بالإنجليزية (تعديل بسيط قابل
  للتراجع). 4) الحفظ. 5) استخدام "معاينة" لعرضه بقيم نموذجية. 6) استخدام
  "إرسال تجريبي" لإرساله إلى بريدك الخاص.
- **النتيجة المتوقعة**: يتم الحفظ بنجاح؛ تعرض المعاينة النسختين العربية
  والإنجليزية مع استبدال كل متغيّر `{{variable}}` بقيمة نموذجية؛ يُرسل
  البريد التجريبي فعليًا دون كشف بيانات اعتماد SMTP في أي مكان بالاستجابة.
